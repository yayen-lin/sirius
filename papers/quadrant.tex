  \caption{
    Each cell shows when the transition began and its most representative systems (not necessarily from that period). Relational data moved from transactional processing (70s--80s) to analytical processing on CPUs ($\sim$mid-1990s)~\cite{StonebrakerPavloAround24}, and then to GPUs (2010s)~\cite{AramburuTheseus25, HeavyDB, Kinetica, Yogatama26}. Vector data is following the same path: vector search answers one query at a time (2020s)~\cite{StonebrakerPavloAround24, WangMilvus21}, and the vector join reached CPU engines in 2024~\cite{DuckDBVSSBlog24} and is now a SQL clause in several~\cite{DatabricksNearestByJoinBlog26, DuckDBNearestByPR24137, SparkNearestByJoin26}. The vector join on the GPU is the open cell that this work fills.
