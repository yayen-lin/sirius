    \caption{
        Exact vector join. Both relations are split into batches, and every probe batch $R_i$ is joined with every corpus batch $S_j$. Each task loads one batch pair onto the GPU; the other batches can be spilled to host memory or disk. Up to $T$ tasks run concurrently, each on its own pair, where $T$ is configurable. Within a pair, Step 1 computes distances with GEMM and Step 2a reduces them tile by tile, so the full $m_i \times n_j$ distance matrix is never built. The top-$k$ modes keep $k$ candidates per row, and global top-$k$ then keeps $k$ per pair; threshold keeps every pair within $\varepsilon$. Step 2b combines the local results of all pairs into the final answer. Per-row top-$k$ holds its local results in a repository until all pairs finish, and that repository can also be spilled to host memory or disk.
